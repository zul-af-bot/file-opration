# File Opration by Zul (TheFlow Pro Edition)

Aplikasi desktop *portable* dengan tema dan logo **TheFlow Pro**, terbagi menjadi **2 Segmen**:

1. **📂 Pindah & Rename File:**
   - Pindahkan (*Move*) atau salin (*Copy*) file secara **langsung** maupun **otomatis (*Watch Folder*)** saat file baru masuk.
   - Filter berdasarkan semua file, hanya video, hanya foto, atau ekstensi kustom.
   - Rename otomatis: tambah awalan/akhiran, penomoran urut (`konten_001`), atau ganti teks dengan *live preview*.

2. **✨ Upscale Foto & Video (1080p):**
   - Mendukung **Foto** (`.png`, `.jpg`, `.jpeg`, `.webp`, `.bmp`) dan **Video** (`.mp4`, `.mov`, `.mkv`, `.webm`, `.avi`, `.m4v`).
   - Pilihan output: tambah akhiran `_1080p` di folder yang sama, timpa file asli (*Overwrite*), atau simpan ke folder lain.
   - Tersedia **Mode Cepat (FFmpeg)** dan **Mode AI (Real-ESRGAN)** serta mode **Pantau Folder Otomatis**.

## Cara Pakai

1. Klik ganda **`Mulai_Upscaler.bat`**.
2. Jika di perangkat baru komponen `FFmpeg` / `AI` belum ada, aplikasi otomatis mengunduhnya sambil menampilkan persentase hingga status menjadi **`Tools: Lengkap ✅`**.
3. Gunakan tombol **`🌙 Tema Emas Gelap`** / **`☀️ Tema Terang`** di kanan atas untuk mengganti tema ala TheFlow Pro.
